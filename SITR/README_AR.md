# سِتر | SITR

تطبيق أندرويد عربي تجريبي لحجب **نطاقات** الإعلانات والمتتبعات على مستوى الجهاز من خلال VPN محلي. يعمل دون روت ودون متصفح.

## الميزات
- مفتاح مستقل لحجب نطاقات الإعلانات، ومفتاح للخصوصية (قواعد تتبع + DNS-over-TLS)، وتشغيلهما معًا.
- يمر عبر VPN **DNS فقط**، وليس كل حركة الإنترنت. لا يخفي عنوان IP، ولا يوفر هوية مجهولة.
- فلاتر مدمجة وتحديث اختياري من ملف hosts الخاص بـ StevenBlack.
- استثناءات نطاقات، وإحصاء محلي لعدد **طلبات DNS** المحجوبة.
- خدمة أمامية مع إشعار صامت وفق متطلبات أندرويد وتذكير كل 24 ساعة قابل للإيقاف.
- استمرار الحماية بعد الخروج من واجهة التطبيق ومحاولة الاستعادة بعد إعادة تشغيل الجهاز إذا بقي إذن VPN متاحًا.

## حدود تقنية لا يجب إخفاؤها
- إعلانات يوتيوب وفيسبوك الرسمية كثيرًا ما تأتي من نطاقات المحتوى نفسها؛ لا يمكن ضمان حجبها عبر DNS، وتعمدنا عدم حجب googlevideo.com أو facebook.com لكيلا يتعطل الفيديو أو الدخول.
- بعض التطبيقات تستخدم DNS مشفرًا خاصًا أو عناوين IP مباشرة وتتجاوز DNS الخاص بالنظام.
- إن فشل DNS-over-TLS، يستخدم الإصدار التجريبي DNS عاديًا حفاظًا على الاتصال **ويظهر تنبيهًا واضحًا داخل الواجهة**. لا تعتبر هذا إخفاءً لهوية المستخدم.
- أندرويد يظهر إشعار خدمة VPN، ولا يمكن إزالة الإشعار الدائم رسميًا مع استمرار الخدمة.
- عداد الحجب يقيس عدد طلبات DNS التي قوبلت بالمنع، وليس عدد الإعلانات المرئية.
- VPN محلي واحد فقط يمكن تشغيله في الوقت نفسه؛ تشغيل VPN آخر يفصل حماية سِتر غالبًا.

## البناء
يتطلب JDK 17 وAndroid SDK API 35 وGradle 8.9.
داخل مجلد SITR:

    gradle :app:testDebugUnitTest :app:assembleDebug

الملف الناتج: app/build/outputs/apk/debug/app-debug.apk

يدير GitHub Actions أيضًا بناء نسخة **تجريبية بتوقيع تصحيح Debug، وليس توقيع إصدار إنتاجي** باسم SITR.apk داخل Releases.

## الخصوصية
لا يستخدم التطبيق تحليلات أو خادمًا تابعًا للمطور. يظل عداد الحجب داخل الهاتف. التحديث الاختياري يتصل بـ GitHub لتنزيل قوائم قواعد. استعلامات DNS غير المحجوبة ترسل إلى Cloudflare (1.1.1.1) عبر TLS في وضع الخصوصية عند نجاح الاتصال، أو إلى خادم DNS تقليدي في وضع الحجب العادي.

## التحقق المطلوب قبل الاعتماد اليومي
اختبر على جهاز Android 8.1 فعلي: الاتصال عبر Wi-Fi والبيانات، تصفح المواقع، اللعب، فتح يوتيوب وفيسبوك، تغيير الشبكة، استعادة VPN بعد إعادة التشغيل، فشل خدمة DNS المشفّر، إشعار الـ24 ساعة، واستهلاك البطارية.

هذا مشروع تجريبي مفتوح للمراجعة، وليس منتجًا جاهزًا مع ضمان منع كل إعلان أو تتبع.
